# Overview

This package provides threat intelligence insights from Orange Cyberdefense Datalake plateform, making it easier for security teams such as SOC and CSIRT to quickly perform alert triage and remediation.

## Supported indicators

As of today, the following indicator types are supported:

- Domain
- Email
- File
- IP
- URL
